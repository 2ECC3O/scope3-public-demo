# Predeclared federal Scope 3 table evaluation

Locked before computing sums, checking percentages, or running a detector. Source: EDGI's public copy of the US federal agency Scope 3 inventory, FY2022 and FY2023, DOI 10.5281/zenodo.19476276. This is an agency-level reported-emissions inventory, not customer activity records or an independently measured ground truth. Raw files remain ignored under `output/practical-evaluation/federal-agencies/`.

Development uses the FY2022 agency and category tables; the FY2023 pair is held out until the implementation and thresholds are frozen. Both are tab-delimited files named CSV. Each has one `Grand Total` row, an `Emissions (MT CO₂e)` whole-tonne value column, and a one-decimal `Percent of Total` column. Agency IDs and category labels must be unique and nonblank; all values finite and nonnegative; exactly one total; all component records present. Explicit mapping selects the ID, value, percentage, total label and unit for each file. A second explicit file provides the other breakdown of the same inventory. CSV delimiter is detected. No row can be silently dropped.

Three checks: (1) component sum against the reported total for each breakdown, allowing at most `(number of components + 1)/2` tonnes for independent whole-tonne rounding; (2) published percentage against 100 × component / reported total, allowing 0.05 percentage points plus 1e-9 for one-decimal rounding; (3) agency and category reported grand totals equal within one tonne. These checks establish internal arithmetic only. Absence of a category, methodological correctness, Scope 3 coverage, and input-activity accuracy remain unverified. The selected files have six grouped categories, not all fifteen distinct GHG Protocol categories.

Development: inspect original FY2022 and use it to correct parser/schema bugs, without changing numeric thresholds. Freeze code and mapping, then run FY2023 once. Separate controlled copies of each year's data add 10,000,000 tonnes to the DOD agency component and 10,000,000 tonnes to the supply-chain category component, leaving published totals and percentages untouched. Declare success only if the aggregate and percentage checks detect both alterations. Report natural check outcomes and controlled outcomes separately; do not label original rows true clean or infer sensitivity/specificity for real reporting errors. Preserve prior EPA v1–v3 and frozen pipeline benchmarks.

## Executed result

The source is EDGI's archived copy of the federal inventory, [Zenodo record](https://zenodo.org/records/19476276), DOI 10.5281/zenodo.19476276. The page describes publication on 4 February 2025 and its current version metadata shows creation/modification on 8 April 2026. It links the original federal inventory page and lists four CSVs. The CSVs downloaded for this evaluation are UTF-16 tab-delimited, despite the `.csv` extension. Their SHA-256 values are recorded in the ignored JSON outputs. Raw files were not added to Git and the Zenodo record does not display an explicit licence in the inspected page.

The reusable checker is `tools/review_inventory_tables.py`; `tools/federal_scope3_mapping.json` maps the source headers, IDs, file paths and required units. It rejects missing, duplicate or nonfinite records, checks the complete expected ID sets for this source, and accepts only an explicit metric-tonnes-CO2e unit. It does not convert physical activity to emissions. Its rules are new standalone arithmetic checks and do not use or alter the existing step-2 detector. A different table can use a different mapping; omit `expected_ids` when the complete ID set is unknown, in which case coverage is unverified and must be interpreted accordingly.

Development FY2022: 22 agency components summed to 135,651,814 against a reported 135,651,812, a +2-tonne difference inside the predeclared 11.5-tonne rounding allowance. Six grouped category components summed exactly to 135,651,812. The two reported grand totals matched, and no published component percentage exceeded the one-decimal rounding allowance. The controlled +10,000,000-tonne alterations to DOD and the grouped supply-chain category each triggered both the relevant sum review and that component's percentage review.

With checker and mapping unchanged (SHA-256 `c9db688202a4773e72cb048f68ec4c5c2698dbefcff6587ea8bb13073d2fbae5` and `d696a23fac5d902382faf9416fed5464174a13d3dc67f4bea58a364b4bc90647`), held-out FY2023 had 22 agency components summing to 135,577,972 against a reported 135,577,971 (+1 tonne, within 11.5); six grouped categories summed exactly to 135,577,971. Both grand totals matched; no percentage was outside the declared tolerance. Both controlled changes triggered the declared sum and percentage checks. Thus 2/2 deliberate alterations were detected in each year, while the original published tables raised no reviews. This is a smoke test of large errors and internal consistency, not a real-error detection rate.

Ignored evidence is `output/practical-evaluation/federal-agencies/{development,evaluation}{,-controlled}.json`. Reproduce with `uv run python tools/review_inventory_tables.py tools/federal_scope3_mapping.json --year 2022`, then `--year 2023`; add `--controlled` for the separate altered-copy check. One development-only input-boundary test passed. Full Scope 3 coverage, input-activity correctness, source calculation methods and applicability to customer records remain unverified. The six published groups include categories 1/2/4 combined and do not establish the full fifteen-category Scope 3 inventory.

## Post-run input hardening

After the held-out run, review found that numeric parsing could silently accept malformed thousands separators or a percent suffix on an emissions value. The importer now validates numeric syntax and field units, requires reporting precision in the mapping (`1` tonne and `0.1` percentage points for this source), reports whether complete component IDs were checked, records checker and mapping hashes, and creates output files exclusively. `tools/fetch_federal_scope3.py` downloads the four source files from the Zenodo record into ignored output and checks their SHA-256 hashes; run `uv run python tools/fetch_federal_scope3.py` before the commands above. It does not redistribute raw files.

These are post-run implementation corrections, not a new held-out study. Two input-boundary tests passed. Repeated development and FY2023 runs were treated only as regression checks: all four saved original/controlled outputs retained the same sum residuals, sum-review decisions and percentage-review IDs. The original saved outputs remain intact. The original-run checker and mapping hashes above identify the pre-hardening version; the hardened runs include their own hashes in ignored `*-hardened.json` files.

Final generic-mapping correction: the cross-table allowance now uses half the sum of both mapped value resolutions, and nonfinite precision settings are rejected. The federal mapping remains 1 tonne for each table, so its cross-table allowance remains 1 tonne. Three input-boundary tests passed; a repeated FY2023 source run retained its original arithmetic outcomes. This repeat is a regression check only.
