# Data and licence scope

This demonstration runs with invented emission factors and waste codes. They
are teaching inputs, not real environmental estimates. No TGO factor list,
private waste-link compilation, regional workbook, source PDF/Excel file, or
historical private Git content is included.

The shared source code still contains an attributed TGO Thailand grid number
and explanatory comments with several factual treatment numbers. Public-demo
mode overrides the Thailand grid number with invented `0.5 kg CO2e/kWh` and
does not use the treatment numbers. These source references are visible to
anyone who reads the public code; they are not a validated public factor set.

`LICENSE` covers this project's original software and documentation. The
bundled React and Lucide assets retain their own licences in
`THIRD-PARTY-NOTICES/`. The project makes no claim to third-party source
publications or databases. This demo cannot validate a real inventory or
establish detector accuracy on customer data.
